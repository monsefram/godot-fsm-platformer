# godot-fsm-platformer

**FR** — Jeu de **plateforme 2D** développé avec **Godot 4 (GDScript)**, structuré autour d'une **machine à états finis (FSM)** pour gérer les états du personnage (repos, course, saut, chute…).

**EN** — A **2D platformer** built with **Godot 4 (GDScript)**, structured around a **finite state machine (FSM)** to manage character states (idle, run, jump, fall…).

---

## Concepts / Highlights

- **FR**
  - Machine à états finis pour un contrôle de personnage clair et extensible.
  - Scènes et scripts séparés (`scenes/`, `scripts/`), ressources dans `assets/`.
  - Physique de plateforme 2D (déplacement, gravité, saut).
- **EN**
  - Finite state machine for clean, extensible character control.
  - Separated scenes and scripts (`scenes/`, `scripts/`), assets in `assets/`.
  - 2D platforming physics (movement, gravity, jump).

## Stack

Godot 4 · GDScript.

## Lancement / Run

**FR** : ouvrir le dossier du projet dans **Godot 4**, puis lancer la scène principale (F5).
**EN**: open the project folder in **Godot 4**, then run the main scene (F5).
